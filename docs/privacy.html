Privacy & data sources

Version 1.0.0 · November 3, 2026

The extension scans technical page text locally. It does not send page text, browsing history, detected parts or personal information to a server. Detected parts exist only in the page's memory. Preferences, excluded sites and optional affiliate links are saved in Chrome local storage until you clear them or uninstall.

No analytics, advertising scripts, remote code, remote database updates or telemetry are included. Selecting a buying or datasheet link opens an external website. That website receives your request and has its own privacy practices. Buying links may earn the publisher a commission. No existing page links or affiliate tags are replaced.

Optional Bridge Mode opens your configured GitHub Pages website with a part ID in its URL. GitHub and linked retailers process ordinary web requests. Direct Amazon affiliate tagging in the extension is disabled. AliExpress links are used only when explicitly configured, and only on a user click.

Reference quality

The bundled database contains 161 component and board records. It is a curated quick reference. All 161 entries now have source-reviewed quick-reference claims. Ten entries use transparently identified manufacturer-authored mirrors or redirected documents; the original AMS host remains unavailable. HC-SR04 and MQ-2 describe documented module variants and do not establish arbitrary board schematics. Source review is not a hardware test or complete circuit qualification. Each card displays its verification note. Source links may point to a manufacturer search rather than a PDF. Always check manufacturer, package, suffix, temperature, schematic and operating conditions. Alternatives require a new suitability assessment.
