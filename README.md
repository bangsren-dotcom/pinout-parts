## 📦 How to Sideload (.zip Installation)

1. Download the `.zip` file from the links above and extract it to a local folder.
2. Open your Chromium browser (Chrome, Edge, Brave, Opera) and go to `chrome://extensions`.
3. Enable **Developer mode** (top right switch).
4. Click **Load unpacked** (top left button) and select the extracted folder.
5. The extension is installed and ready to use!

## 🔒 Privacy Guarantee
* **No Telemetry**: These extensions do NOT collect analytics, track URLs, or report user activity to third-party servers.
* **Local Processing**: All parsing, decoding, and extraction is computed strictly inside the browser sandbox.
